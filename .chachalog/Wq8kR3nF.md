Areas and content lists now carry the same name and picture wherever they appear: an area reads as "Area" in jContent and Content Editor instead of the content list it is stored as, and a list built on a specific content type shows that type in Page Builder - a Section reads as "Section" rather than "List". The Page Builder labels are also translated now, where they used to be English whatever the interface language.
